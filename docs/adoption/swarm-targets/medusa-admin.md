POLICY GATE (read first): Medusa wants an issue first, then assignment by a maintainer before a PR, and its bot closes PRs not linked to an assigned issue; its automation may also fix a small UI bug itself. Prepare the issue first and the PR second, and say in the report that the PR waits for assignment.

Where the notes below differ from the policy gate above (for example a fix patch or PR text), the gate wins.

Why: Very large reach (37k stars) and a native path (create-medusa-app, Postgres from apt). Open issue #17149 reports stale localized query results (caching). Policy is strict on AI wording, so the owner must write the issue and PR text personally.
