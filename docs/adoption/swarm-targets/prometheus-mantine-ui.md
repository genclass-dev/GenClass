Know before exploring: every request goes through src/api/api.ts (useAPIQuery: queryKey [path, params] or an explicit key, gcTime 0, fetch with the TanStack signal; useSuspenseAPIQuery adds staleTime Infinity from #17357). Graph.tsx keys on expr/end/range/step with keepPreviousData, TableTab.tsx keys on [useId(), "/query", expr, endTime, retriggerIdx], ExpressionInput.tsx handleFormat has a generation guard, and QueryLifecycle.test.tsx already asserts that an obsolete graph request is aborted. The open lead is TreeNode.tsx L129-136: the per-node /query uses key [useId()] with the node's query only in params, so a surviving node instance under an expression edit may keep or mis-attribute data; next are the delete_series form in TSDBStatusPage.tsx (raw POST, `deleting` flag only) and NotificationsProvider.tsx (SSE plus polling fallback). Targets, Service discovery, Alerts and Rules filter client-side on one suspense query; only the pool select changes a request. Expect to report a false-report rate on the correct variant even if no race is found.
