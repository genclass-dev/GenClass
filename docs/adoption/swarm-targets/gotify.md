Surfaces, all in ui/src: (1) message/MessagesStore.ts loadMore appends GET /message?since= pages while reactions.ts -> wsStore.listen -> publishSingleMessage unshifts /stream deliveries with no de-duplication by id; a push during the first page's flight shows twice and getUnCached hides both copies on pending delete, which is open issue #680 word for word. (2) loadMore's single `loading` flag is shared across apps and refreshByApp calls clearAll() then loadMore, so an in-flight page lands in the detached old state and a navigation during a load is skipped (Messages.tsx useEffect on appId only). (3) removeSingle checks pendingDeletes before the await and clears after: snackbar onExited plus pagehide inside the window still send two DELETEs; #1075 only removed the beforeunload listener. (4) application/AddApplicationDialog.tsx and client/AddClientDialog.tsx never disable Create during appStore.create/clientStore.create: two POSTs. (5) common/BaseStore.ts refresh writes whichever list GET resolves last after create/update/remove.
