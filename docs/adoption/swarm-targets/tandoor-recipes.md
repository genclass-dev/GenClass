# Tandoor Recipes

Session brief for the adoption swarm (docs/adoption/swarm.md), 2026-11-03. Slug `tandoor-recipes`, type hunt.

TARGET: Tandoor Recipes (TandoorRecipes/recipes). TYPE: hunt (`docs/adoption/swarm.md` section 4.1). SLUG: tandoor-recipes.

Why: Recipe search with filters, the shopping list (check/uncheck and autosave), meal plans and the recipe editor are all write-then-refetch flows over a generated fetch client, and a closed issue (#4830 'Meal plan servings are overwritten by the recipe's servings after every save') shows the lost-edit class already bit this UI. Dev setup is the simplest in the batch (SQLite, two commands). 8.7k stars; Commons Clause licence and a CLA mean a human contributor must sign before the PR.

What to contribute: docs/adoption/hunts/tandoor.md, a patch to vue3/src (store/composable sequencing for the affected flow) with a test in the project's style, an issue draft and a PR draft with AI-assistance disclosure; a human signs the CLA.

Mechanism: PR to TandoorRecipes/recipes (develop): 'If you want to contribute bug fixes or small tweaks then your pull requests are always welcome!'; CLA via https://cla-assistant.io/TandoorRecipes/recipes; guidelines: https://github.com/TandoorRecipes/recipes/blob/develop/docs/contribute/guidelines.md

Stack: Backend: Django (python manage.py runserver), SQLite by default with no env vars. Frontend: vue3/ Vue 3.5 + Pinia 4 + Vuetify with a generated OpenAPI client (vue3/src/openapi), Vite dev server via `yarn serve`.
