TARGET: Linkwarden (linkwarden/linkwarden). TYPE: hunt (`docs/adoption/swarm.md` section 4.1). SLUG: linkwarden.

Why: A bookmark manager whose UI is pure fetch-then-render over react-query: link search-as-you-type, link edit modals (title/collection/tags), collection moves, bulk actions, pinned toggles and infinite-scroll lists with sort/filter. Runs natively with apt PostgreSQL (`yarn web:dev` on localhost:3000). The repo keeps an AGENTS.md for coding agents and the maintainer asks only to 'stay in touch' before starting. 20.3k stars, AGPL-3.0. No race issue found yet, so the hunt would be the first.

What to contribute: docs/adoption/hunts/linkwarden.md, a patch to apps/web (query keys/cancellation in the affected hook or modal) with a Vitest test (root vitest.config.mts), an issue draft and a PR draft with AI-assistance disclosure.

Stack: Yarn 4 monorepo: apps/web Next.js 15.5 (React 19, @tanstack/react-query 5, axios, zustand 4) + apps/worker (tsx) on PostgreSQL via Prisma; Meilisearch optional (client initialised only when MEILI_MASTER_KEY is set); Chromium via Playwright for preservation.
