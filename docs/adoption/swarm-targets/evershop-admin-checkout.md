# EverShop admin and checkout

Session brief for the adoption swarm (docs/adoption/swarm.md), 2026-11-03. Slug `evershop-admin-checkout`, type hunt.

TARGET: EverShop admin and checkout (evershopcommerce/evershop). TYPE: hunt (`docs/adoption/swarm.md` section 4.1). SLUG: evershop-admin-checkout.

Why: Native by design (Node + an empty Postgres database, npm run setup / npm run dev, admin at /admin on :3000) and a GPL e-commerce stack whose checkout is a chain of sequential POSTs (add to cart, coupon, shipping, payment) plus admin grids driven by URL filters and product edit forms with variants. Issue #346 (order created even if the PayPal redirect fails) shows ordering problems in checkout. Double submit is guarded in the shared Form; stale responses in grids and cart updates are the open question.

What to contribute: Hunt on the admin product/order grids and the storefront cart/checkout; fix PR in packages/evershop/src with a test in the package's style; issue + hunt report.

Mechanism: PR to https://github.com/evershopcommerce/evershop against the dev branch (packages/evershop/src/components/... or src/modules/...), issue via the bug template (asks for the Postgres version).

Stack: Node ESM + Express + PostgreSQL; admin and storefront React 19 with urql 3 (GraphQL), react-hook-form 7.61, axios 1.20; forms post with fetch and disable the fieldset while loading (components/common/form/Form.tsx L68-180); default branch dev.
